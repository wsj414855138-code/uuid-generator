UUID v7 to timestamp

Paste a version 7 UUID to read the millisecond timestamp in its first 48 bits. The same form also reports the version and variant of any canonical UUID.

Decode a UUID

Hyphens are optional. A leading urn:uuid: is ignored. Up to 200 lines.

Paste a UUID to see its version, variant, and the version 7 time when it has one.

The decoder accepts the 36-character form, 32 hexadecimal digits without hyphens, and an optional urn:uuid: prefix.

A version 7 value that does not use the RFC variant (the high bits 10) is still reported, but the Unix timestamp is only defined for that variant. Version 4 has no timestamp field.

Questions

What time is extracted?

For a version 7 UUID in the RFC variant, the first 48 bits are a Unix timestamp in milliseconds. The page prints that integer and the matching UTC time in ISO 8601. It does not read a sub-millisecond fraction.

What about other versions?

The page still reports the version nibble and the variant. It does not convert version 1 or version 6 Gregorian timestamps.

Does a decoded time prove when a row was inserted?

No. It is only the timestamp written into the UUID. Clocks can be wrong, and the identifier can be copied later.
