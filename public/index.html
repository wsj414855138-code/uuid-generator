    What this page makes

    A 128-bit id

    A UUID is a 36-character identifier, hyphens included, used to label records without a central counter.

    Version 4 only

    The version digit is 4. The variant digit is 8, 9, a, or b. The rest comes from a cryptographic random source.

    Unique in the batch

    This page drops duplicates inside one batch. It cannot promise that a value will never match an id made elsewhere.

    Questions

    Which UUID version is this?

    Random UUID v4, built with the browser’s cryptographic random generator and shown in lowercase with hyphens.

    Could two results match?

    A collision inside one batch is checked and replaced. Across all users and all time, random ids are extremely unlikely to match, but no generator can promise they never will.

    Do you keep what I generate?

    No. Nothing is sent to a server. Refreshing, switching language, or generating again clears the previous list. There is no account and no history.

    Can I use a UUID as a password?

    No. Treat it as an identifier for data, not as a secret, login, or payment credential.
