    What the two versions contain

    128 bits

    Both versions are 16 bytes, written as 36 characters with hyphens.

    Version 4

    The version digit is 4 and the variant digit is 8, 9, a, or b. The other bits come from a cryptographic random source.

    Version 7

    The first 48 bits are a Unix timestamp in milliseconds. The version digit is 7. The remaining 74 bits are random on this page.

    Questions

    Which versions does this generate?

    This page generates UUID v4 and UUID v7. Version 4 is random. Version 7 places a 48-bit Unix millisecond timestamp in front, then the version and variant bits, then random bits from crypto.getRandomValues. The selected default is version 4.

    Does UUID v7 increase with time?

    Values from later milliseconds sort after values from earlier milliseconds when compared as 128-bit numbers or as canonical hex strings. This generator fills the other 74 bits at random. It does not use a counter, so two values from the same millisecond are not ordered.

    Could two results match?

    Duplicates inside one batch are replaced. A match with an identifier created somewhere else is extremely unlikely. No random generator can promise that a match is impossible.

    Is the result stored?

    No. The browser creates the values. Nothing is uploaded. Refreshing, switching language, or generating again clears the list.

    Can I use a UUID as a password?

    No. A UUID identifies a record. It is not a password, a session token, or a signing key.
