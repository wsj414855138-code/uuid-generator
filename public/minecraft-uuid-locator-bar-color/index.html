How the color is chosen

The Locator Bar page on the Minecraft Wiki says that Java Edition assigns a waypoint color from the entity UUID. The same page says a team color or the /waypoint command can replace it, and that Bedrock Edition assigns a color at random for each session. Checked against that entry, the wiki does not publish a different bit formula.

This page follows Java UUID.hashCode(): XOR the two 64-bit halves, then XOR the high and low 32 bits of that result. The low 24 bits are RGB. That color is converted to HSV, the value V is set to 0.9, and it is converted back to RGB. The swatch uses the color after that step.

Username lookup uses PlayerDB at https://playerdb.co/api/player/minecraft/<name>. api.mojang.com does not send a CORS header that browsers can read, so this page does not call it. A pasted UUID is not sent anywhere.

Questions

Is this the color shown in game?

It is the Java Edition default derived from the UUID. The Minecraft Wiki says a team color or the /waypoint command can replace that default. Bedrock Edition picks a color for each session, so this page does not apply there.

Does a username change the color?

An online-mode Java account keeps the same UUID when the username changes, so the default color stays the same. On an offline-mode server the UUID is derived from the name, and a different name can mean a different color.

Which service resolves the username?

The page asks PlayerDB. api.mojang.com does not send a CORS header that browsers can use. Pasting a UUID skips the lookup, and the color math runs in the browser either way.
