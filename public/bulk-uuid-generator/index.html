    Questions

    How many can I generate?

    From 1 to 10000 in one batch. The page previews the first 20. Copy all and the file downloads include the full batch.

    Are the files uploaded?

    No. TXT, CSV, and JSON are created in the browser and downloaded to your computer.

    Which version should I pick?

    Use v4 for random identifiers. Use v7 when you want new values to sort near each other by millisecond. v7 on this page is still not a counter inside one millisecond.
