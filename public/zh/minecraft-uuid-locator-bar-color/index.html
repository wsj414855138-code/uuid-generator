颜色是怎么来的

Minecraft Wiki 的 Locator Bar 条目写明：Java 版根据实体的 UUID 指定路标颜色；队伍颜色或 /waypoint 命令可以改掉它；基岩版则在每次会话随机指定。对照该条目，Wiki 没有公布另一套位运算公式。

本页使用 Java 的 UUID.hashCode()：先把两个 64 位半异或，再把结果的高 32 位和低 32 位异或。取低 24 位作为 RGB，转到 HSV 后把亮度 V 设为 0.9，再转回 RGB。色块显示的是这一步之后的颜色。

用户名查询使用 PlayerDB，地址是 https://playerdb.co/api/player/minecraft/<name>。api.mojang.com 不返回浏览器能读取的 CORS 头，所以本页不调用它。粘贴的 UUID 不会被发送出去。

常见问题

这就是游戏里看到的颜色吗？

这是由 UUID 算出的 Java 版默认颜色。Minecraft Wiki 写明，队伍颜色或 /waypoint 命令可以换掉这个默认值。基岩版每次会话会重新随机指定颜色，所以本页不适用于基岩版。

改用户名会改颜色吗？

正版 Java 账号改用户名后 UUID 不变，默认颜色也不变。离线模式服务器的 UUID 由名字派生，换一个名字可能得到另一种颜色。

用户名是向哪里查询的？

本页向 PlayerDB 查询。api.mojang.com 不返回浏览器可用的 CORS 头。直接粘贴 UUID 不会发起查询，颜色都在浏览器里计算。
